How It Works:

1. Sensor Input: 5 IR sensors continuously scan for the black line, sampling ~100 times per second.

2. Error Calculation: The microcontroller compares sensor values to determine if the robot is to the left, right, or centered on the line.

3. Decision Logic: Based on the error, the algorithm adjusts motor speeds to steer the robot back to center.

4. PID Control: Proportional-Integral-Derivative control ensures smooth, optimized corrections without oscillation.

5. Error Recovery: If the line is lost, the robot searches left and right to reacquire it.

6. Continuous Loop: This process repeats continuously, allowing the robot to track the line in real-time.
